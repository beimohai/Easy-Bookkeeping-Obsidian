## 项目简介

Easy Bookkeeping 是一款 [Obsidian](https://obsidian.md/) 极简记账插件，提供桌面版、手机版两种记账模式，用于本地记账。它可以轻松实现：

- **跨平台**：手机、电脑均可使用，可以使用 CSV 转移账目；
- **多语言**：支持简体中文、繁体中文、英语、日语、韩语等 12 种语言；
- **极简记账**：分类简洁，可在一次会话中连续快速录入多条不同日期的账目；
- **多种图表**：收支折线图、日历图、饼状图、标签汇总、预算和账户余额；
- **多维表格**：清晰展示多个账目的明细，多重排序方式；
- **多元筛选**：基础筛选、范围筛选、跨月筛选，筛选可导出。

它不依赖第三方服务，所有数据以 Markdown 文件形式保存在本地，完全开源、可高度自定义。

## 快速入门

### 从 GitHub Releases 安装

1. 从 [Releases](https://github.com/beimohai/Easy-Bookkeeping-Obsidian/releases/latest) 下载最新版安装包；
2. 将安装包中的 `easy-bookkeeping` 文件夹解压到 Obsidian 仓库的 `.obsidian/plugins/` 目录（需打开显示隐藏文件夹）；
3. 重启 Obsidian，在“设置 → 第三方插件”中启用 **Easy Bookkeeping**。

### 从网盘安装

1. 点击[夸克网盘](https://pan.quark.cn/s/6e91aa90fec6)，订阅链接并转存，下载最新版安装包；
2. 后续步骤同上。

### 从 BRAT 安装

1. 从 Obsidian 插件市场安装 [BRAT](obsidian://show-plugin?id=obsidian42-brat)；
2. 选择“Add Beta plugin”，输入仓库地址 `https://github.com/beimohai/Easy-Bookkeeping-Obsidian`。

### 从源码构建

源码包包含完整 TypeScript 源码、资源文件、锁定的开发依赖和构建配置。安装 Node.js 20 或更高版本后运行：

```bash
npm ci
npm run build
```

生产构建会执行 TypeScript 类型检查，并在项目根目录生成压缩后的 `main.js`。源码构建所需的 npm 包仅用于开发，不是插件的运行时依赖。

## 功能概览

### 1. 快速记账与输入校验

- 桌面版使用单输入框完成日期、账户、类型、必要性、分类、附件、内容、金额和备注录入，全程可以不离开键盘；
- 桌面版与手机版均可选择连续记账，仪表盘中新建账目会自动使用当前查看的月份；
- 记账方式可自动识别设备，也可固定为桌面版或手机版；
- 账户、类型、必要性、分类和附件均可独立启用、隐藏和拖动排序；
- 类型、必要性、分类和账户预设支持新增、删除、重命名、自定义唯一编号、拖动排序和默认值；类型还可设置为收入、支出或不计入；
- 金额支持普通数值与四则运算表达式，例如 `11.4+5.1-4`；任一数值超过两位小数时会直接提示错误，不会静默舍入后创建；
- 支持自定义记账快捷键、全局快捷键、同日内容重复校验和附件拖放或文件选择。

### 2. 月度仪表盘与年度统计

- 按月汇总收入、支出、结余和账目数量，切换月份后录入月份同步变化；
- 可选择离开仪表盘后不保持、保持当前筛选，或分别恢复每个月的界面状态；
- 顶部功能按钮支持显示、收进菜单和拖动排序；
- 年度统计保留分月收入、支出、结余和账目数量表格，并提供单列年度图表；
- 仪表盘可手动刷新账目，也可直接进入图表管理、标签管理、CSV 导入导出、年度统计和设置。

### 3. 可配置图表

- 每日趋势支持收入、支出、结余和余额指标，可切换折线图、面积图或柱状图；
- 日历图支持每日收入、支出和结余，周起始日可设置为周日至周六任意一天；
- 饼状图支持支出分类、收入分类、必要性、账户支出、账户收入和账户余额占比，并同时显示金额和百分比；
- 标签汇总支持收入、支出、结余和账目数量，并可按金额或标签名正序、倒序排列；
- 预算进度和账户余额与其他图表同级，可进入专用面板调整预算和月初余额；
- 图表可以添加、删除、隐藏、复制配置、拖动排序，并在半栏与通栏宽度之间切换；统计卡片和全部图表都会跟随当前筛选结果。

### 4. 多维账目明细

- 表头名称、顺序、显示状态、行内编辑权限和列宽均可自定义；列宽可拖动调整，也可一键恢复默认宽度；
- 顶部与底部横向滚动条常驻显示并与表格双向同步，选择列固定在最左侧；
- 日期支持主排序锁定；在同一日期内可按时刻、内容、类型、必要性、分类、账户或金额进行次级排序；
- 开启行内编辑后，可按列修改日期、内容、预设字段、金额公式、备注和标签，非法输入会显示中文提示；
- 支持多选账目后批量修改日期、类型、必要性、账户、分类和标签，或批量删除；
- 过长内容、备注、标签和预设值会按可用宽度省略，完整信息仍可通过编辑或交互查看。

### 5. 联动筛选与搜索

- 类型、必要性、分类、账户和标签均支持多选、全选、按当前结果联动和关键词搜索；
- 支持内容、备注和标签关键词搜索，以及金额上下限和起止日期范围；
- 金额范围仅接受非负且最多两位小数的数值，日期和金额范围都会校验上下限；
- 跨月选项对全部筛选条件生效；启用后可以在所有账目中组合检索；
- 搜索、明细列表、统计卡片和图表使用同一份筛选结果；筛选结果还可直接导出 CSV；
- 点击账户余额、标签汇总、标签数量或账目标签，可在保持页面位置的同时应用相应筛选。

### 6. 账户、预算、标签与附件

- 支持多账户、自定义账户编号和顺序、账户间转账，以及逐月修改月初余额；下月余额会依据本月收支自动结转；
- 支持总预算和分类预算，并在图表中直观显示使用进度；
- 标签支持单笔交互添加、移除，以及全局重命名、删除和批量处理关联账目；
- 小票或发票可拖入桌面端上传框，手机端可调用文件选择；附件自动保存到指定仓库目录并按对应账目文件命名；
- Markdown 文件和账目编辑面板均可预览附件，点击预览可打开原文件。

### 7. 数据导入、导出与迁移

- CSV 导入会识别列映射和元数据差异，在转换为当前预设前请求确认；
- 导入过程显示百分比，并统计失败行及具体原因，不会静默跳过错误数据；
- CSV 导出支持全部账目、当前月份、当前筛选结果或自定义日期范围，并可设置文件名和保存位置；
- 桌面端可以通过系统保存对话框导出到仓库外任意目录；
- 旧版转换支持选择仓库内目录原地转换，或选择外部文件夹后导入当前账目目录；原外部文件保持不变；
- 旧备注中的算式可以迁移到独立算式字段，转换时会跳过重复账目并显示进度。

### 8. 本地文件、恢复与安全操作

- 每笔账目独立保存为 Markdown，账户和分类即使未启用也会写入默认占位值，算式字段始终保留；
- 可选择是否把算式同时写入备注，修改存储方式时可同步转换现有文件；
- 删除支持二次确认和 0—15 秒可配置撤销时间；
- 文件变更会自动刷新，必要时可手动重新扫描仪表盘；
- 上传插件市场后由 Obsidian 负责更新；手动安装时可通过 GitHub Releases 或网盘重新下载新版。

### 9. 高度自定义与响应式界面

- 可配置货币符号、收入与支出颜色、中文万位或国际千位分组、年月、日期、时间和日历格式；
- 图表、顶部按钮、录入字段、预设、表头和快捷键均可独立配置；
- 手机、平板和桌面端根据可用宽度自动重排，手机端统计卡片保持两列，图表自动切换为单列；
- 12 种界面语言覆盖设置、录入、仪表盘、筛选、统计和提示；账目内容、用户标签及备注保持原文，不被翻译。

## 文件结构

每一笔账目保存为一个 Markdown 文件，例如：

```yaml
---
记账插件: true
账目ID: mabc1234-abcdefgh
时间: 2026-07-21 11:45
类型: 支出
标签: 必需
分类: 未分类
账户: 默认账户
内容: 午餐
金额: 19.19
算式: "19.19"
备注: 无
tags:
  - 记账
附件: []
---
```

```text
Obsidian/
  └─ 你的存放目录/
	├─ YYYY/
	│	└─ MM/
	│		└─ DD/
	│			└─ 账目文件.md	# 一条账目一个文件
	├─ 导出/
	│	└─ 账目导出.csv
	└─ 附件/
		└─ YYYY/
			└─ MM/
				└─ DD/
					└─ 账目附件.md
```
